Диплом часть 2: API

Реализованы следующие тесты:

Создание пользователя:

создание уникального пользователя,
создание пользователя, который уже был зарегистрирован
создание пользователя с не заполненным полем: "email"

Авторизация пользователя:
под существующим логином,
под логином и паролем, которые не верны

Изменение данных пользователя:

ранее авторизованного
без авторизации

Создание заказа:
авторизованным пользователем,
пользователем не авторизованным,
с ингредиентами,
без ингредиентов,
с неверным хешем ингредиентов

Получение заказов конкретного пользователя:

авторизованного пользователя
неавторизованного пользователя
